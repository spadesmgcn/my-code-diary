# MySQL 基础：创建数据库并插入数据

## 一、数据库操作

### 建立数据库
```sql
CREATE DATABASE 名称;
```

### 连接数据库
```sql
USE 名称;
```

### 查看当前数据库中的所有表
```sql
SHOW TABLES;
```

> 补充：如果忘了自己现在在哪个数据库里，可以用 `SELECT DATABASE();` 查看当前所在的数据库。

---

## 二、数据表（Table）

### 新建数据表
```sql
CREATE TABLE 表的名字 (
    列名a 数据类型(数据长度),
    列名b 数据类型(数据长度),
    列名c 数据类型(数据长度)
);
```

### 常用数据类型

| 类型 | 说明 | 举例 |
|---|---|---|
| INT | 整数 | 学号、年龄、数量 |
| FLOAT | 单精度小数 | 粗略的价格、比率 |
| DOUBLE | 双精度小数 | 精确的成绩、金额 |
| DECIMAL(M,D) | 定点小数，M为总位数，D为小数位数 | 财务金额 |
| CHAR(n) | 固定长度字符串，不足补空格 | 性别、身份证号 |
| VARCHAR(n) | 可变长度字符串，按实际长度存储 | 姓名、地址 |
| TEXT | 大段文字 | 文章内容、备注 |
| DATE | 日期（年-月-日） | 2026-06-04 |
| TIME | 时间（时:分:秒） | 21:22:00 |
| ENUM | 枚举，从预定义值中选一个 | ENUM('男','女') |

### 易踩坑：CHAR 与 VARCHAR 怎么选？

- **CHAR(n)**：不管你实际存了几个字，它都会占满 n 个字符的空间。适合存**长度固定**的数据，比如身份证号（固定18位）。
- **VARCHAR(n)**：存多少占多少，不浪费空间。适合存**长度不确定**的数据，比如姓名（有人叫"李明"，有人叫"欧阳娜娜"）。
- 拿不准的时候，**无脑选 VARCHAR** 就对了。

## 三、插入数据

```sql
INSERT INTO 表的名字(列名a, 列名b, 列名c) VALUES(值1, 值2, 值3);
```

**注意**：
- 需要加**单引号**的类型：CHAR、VARCHAR、TEXT、DATE、TIME、ENUM
- **不需要**加单引号的类型：INT、FLOAT、DOUBLE

### 易踩坑：插入数据常见报错

1. **列数和值的数量不匹配**：表有3列，VALUES里只给了2个值，直接报错。
2. **字符串忘了加单引号**：`VALUES(1, 数据结构, 50)` 会报错，必须写成 `VALUES(1, '数据结构', 50)`。
3. **中文乱码**：如果插入中文后显示乱码，说明建库时没指定字符集。建库时加上：
```sql
CREATE DATABASE 名称 DEFAULT CHARSET=utf8mb4;
```

## 四、查看表内容

```sql
SELECT * FROM 表的名字;
```

### 实用扩展：不只是 SELECT *

| 语句 | 作用 |
|---|---|
| `SELECT * FROM book;` | 查看所有列、所有行 |
| `SELECT name FROM book;` | 只看 name 这一列 |
| `SELECT * FROM book WHERE price > 60;` | 只看价格大于60的行 |
| `DESC book;` | 查看表的结构（有哪些列、什么类型） |

> 补充：`SELECT *` 虽然方便，但在实际开发中尽量少用。因为表的列很多时，`SELECT *` 会把所有列全部取出来，浪费性能。养成习惯写明具体需要的列名。

## 五、删除操作（谨慎使用）

| 语句 | 作用 | 危险程度 |
|---|---|---|
| `DROP DATABASE 名称;` | 删除整个数据库 | ⚠️ 极高 |
| `DROP TABLE 表名;` | 删除整张表 | ⚠️ 高 |
| `DELETE FROM 表名 WHERE 条件;` | 删除符合条件的行 | 中 |

> **铁律：执行任何 DELETE 或 DROP 之前，先用 SELECT 确认你要删的东西是对的。删了就没了，没有撤销键。**
